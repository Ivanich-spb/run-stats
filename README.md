# 🏃 Дневник пробежек

CLI для ведения беговых тренировок: добавление пробежек, недельные/месячные сводки, рекорды и сравнение прогресса.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Альтернатива через Makefile:

```bash
make install
```

## Команды

### ✅ Добавить пробежку

```bash
./run add 5.2km 27:30
./run add 10km 58:45 --note "последние 2км умирал"
./run add 5km 27:30 --date 2025-02-01
./run add 800m 3:20
./run add 5,2 27:30
./run add 21.1km 1:34:28
RUN_UNIT=mi ./run add 3.1 27:30
```

Опции и ввод:
- Дистанция: по умолчанию километры, можно `km`, `mi`, `m`, либо без суффикса.
- Десятичная точка или запятая: `5.2` или `5,2`.
- `--note` — заметка к тренировке.
- `--date` — дата пробежки в формате `YYYY-MM-DD` (по умолчанию сегодня).
- Длительность: `MM:SS` или `HH:MM:SS` (если указан час).

### 📅 Сводка за неделю

```bash
./run week
./run --no-style week
./run --no-color week
```

Показывает: количество пробежек, общий километраж, средний темп.

### 🗓️ Сводка за месяц

```bash
./run month
```

Показывает статистику за текущий календарный месяц.

### 🏆 Рекорд на дистанции

```bash
./run best 5km
```

Ищет лучший результат на точной дистанции.

### 📈 Прогресс по неделям

```bash
./run progress
```

Таблица по неделям: пробежки, километры, средний темп.

### ⚖️ Сравнение недель

```bash
./run compare --weeks 4
```

Сравнивает последние `N` недель с предыдущими `N`.

## Примеры вывода

Примеры с эмодзи (без цветов):

```text
$ ./run add 5.2km 27:30
✅ Записано: 5.2км за 27:30
```

```text
$ ./run week
📅 На этой неделе: 3 пробежки, 21.4км, средний темп 5:32/км
```

```text
$ ./run best 5km
🏆 Рекорд на 5км: 24:15 (был 15.02.2025)
```

Примеры без стилей (только таблицы):

```text
$ ./run --no-style progress
Неделя     | Пробежки |   Км | Средний темп
2025-02-03 |        3 | 21.4 |      5:32/км
2025-02-10 |        2 | 16.0 |      5:41/км
```

```text
$ ./run --no-style compare --weeks 2
Сравнение за 2 недели:
Период              | Пробежки |   Км | Средний темп
Последние 2 недели  |        3 | 21.4 |      5:32/км
Предыдущие 2 недели |        2 | 16.0 |      5:41/км
Разница по километражу: +5.4км
```

## Хранилище данных

По умолчанию данные сохраняются в `runs.db` в текущей директории.
Для тестов и отладки можно указать путь через переменную окружения:

```bash
RUN_DB=/tmp/runs.db ./run week
```

## Переменные окружения

- `RUN_DB` — путь к SQLite базе.
- `RUN_TODAY` — дата "сегодня" в формате `YYYY-MM-DD` (полезно для тестов).
- `RUN_UNIT` — единицы расстояния по умолчанию: `km` или `mi` (по умолчанию `km`).

## Стиль вывода

По умолчанию при запуске в терминале включены цвет и эмодзи. Отключить можно флагами:
- `--no-style` — без цвета и эмодзи.
- `--no-color` — без цвета (эмодзи остаются).
